# ODC MCP surface snapshot - 2026-10-30

Full re-probe baseline (full re-probe 2026-10-30: complete schema load plus
throwaway-asset runs). Tool names and parameter names, types and required
flags only; descriptions deliberately omitted (they drift and are not proof,
see `../mcp-surface.md`, heading "Re-probing the surface"), except the
DEPRECATED marker list below, which the drift check compares. Server host
omitted (tenant-neutral). Source: live schema load of every OutSystems MCP
tool, 2026-10-30, plus throwaway-asset runs. 54 tools.

required. `{}` means no parameters. `uuid` = string with uuid format.

required flags are unchanged. Description changes, invisible to names and
parameters: `mentor_create_asset` and `mentor_load_asset` are marked
DEPRECATED, and `mentor_request_upload` allows images.
