# ODC MCP surface snapshot - 2026-10-16

Full re-probe baseline (full re-probe 2026-10-16: complete schema load plus a
throwaway-app run). Tool names and parameter names, types and required
flags only; descriptions deliberately omitted (they drift and are not proof,
see `../mcp-surface.md`, heading "Re-probing the surface"). Server host omitted
(tenant-neutral). Source: live schema load of every OutSystems MCP tool,
2026-10-16, plus a throwaway-app run. 54 tools.

Format: `tool` then one line per parameter: `name: type` and `REQ` when
required. `{}` means no parameters. `uuid` = string with uuid format.
Versus 2026-10-09 (59 tools): added none; absent `db_query`, `exec_in_app`,
`mentor_publish`, `test_setup_start`, `test_setup_status`. Parameter change:
`context_graph` gained `cursor: string`. Every other surviving tool's
parameters, types and required flags are unchanged.
Absent from this surface (do not re-add without a new snapshot): `app_create`,
`publish_start`, `mentor_start`, `mentor_cancel`, `mentor_publish`, `db_query`,
`exec_in_app`, `test_setup_start`, `test_setup_status`.
